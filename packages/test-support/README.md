# @aharness/test-support

Shared fixtures and app-server test utilities for `@aharness/core`.

```sh
npm install --save-dev @aharness/test-support
```

This package is intended for Harness integration tests. It publishes the same
release version as `@aharness/core` and has a regular dependency on
`@aharness/core`; it is not a peer dependency.
